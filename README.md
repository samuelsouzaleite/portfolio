# Portfólio — Samuel Souza Leite

**Acesse em: [samuelsouzaleite.com](https://samuelsouzaleite.com)**

Portfólio pessoal de **desenvolvedor fullstack**, construído do zero com **HTML, CSS e JavaScript puro** (sem frameworks). Apresenta minha trajetória, especializações, habilidades e projetos, com um visual inspirado em material editorial impresso (papel, tinta e vermelho-tijolo).

---

## Funcionalidades

- **Visual editorial** com tipografia serifada, textura de papel granulado e retícula de pontos no hero
- **Modo claro e escuro**, que segue o tema do sistema na primeira visita e salva a escolha no navegador (sem "piscar" ao carregar)
- **Alternador de idioma PT / EN**, com a preferência salva no navegador
- **Efeito de digitação** no hero e **animações de reveal** ao rolar a página
- **Barra de progresso de leitura** no cabeçalho e destaque da seção atual no menu
- **Modal de vídeo nos projetos**: o botão "Visualizar" abre uma prévia do projeto rodando, com descrição
- **Habilidades em acordeão**, com uma descrição curta de cada tecnologia
- **Layout totalmente responsivo** (celular, tablet e desktop), com menu próprio no mobile
- **Formulário de contato funcional** via [Formspree](https://formspree.io)
- Respeita a preferência de **movimento reduzido** do sistema

## Tecnologias

- HTML5 semântico
- CSS3: Grid, Flexbox, variáveis (tokens de tema), animações e `color-mix`
- JavaScript (Vanilla)
- [Google Fonts](https://fonts.google.com): Instrument Serif, Archivo e DM Mono
- Hospedagem no **GitHub Pages** com domínio próprio
